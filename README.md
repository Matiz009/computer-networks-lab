# Computer Networks Lab

Lab work and assignments from my Data Communication and Computer Networks (DCCN) course.

## Features

- Cisco Packet Tracer topologies (`.pkt` files)
- Notes on Cisco commands, DHCP and DNS setup, and inter-VLAN routing with a router
- Link-failure scenario captures (before and after)
- NS2 network simulation scripts in Tcl (`NS2/`)
- Assignment briefs and solutions (`Assignments/`)

## Tech stack

Cisco Packet Tracer, NS2 (Tcl)

## Getting started

```bash
git clone https://github.com/Matiz009/computer-networks-lab.git
```

- Open the `.pkt` files in Cisco Packet Tracer.
- Run an NS2 script with `ns NS2/programme1.tcl` (NS2 has to be installed).

## Project structure

```
Assignments/                 Assignment briefs (PDF) and solutions

lab-task-6th-April-2022/     Lab task notes and screenshots
```
